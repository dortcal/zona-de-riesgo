# Zona de Riesgo

Juego de preguntas sobre agentes físicos (ruido, vibraciones, ambiente térmico, iluminación y radiaciones) para el módulo de IPE.

Diseñado por LPP.

- Se juega desde el navegador del móvil o del ordenador.
- Se puede instalar en la pantalla de inicio y funciona sin conexión después de la primera visita.
